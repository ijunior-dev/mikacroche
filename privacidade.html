Política de Privacidade

Última atualização: setembro de 2026

1. Quem trata seus dados

Mika Paixão Crochê, ateliê de crochê manual sediado em Recife, PE, é responsável pelo tratamento dos dados descritos nesta política, em conformidade com a Lei Geral de Proteção de Dados (Lei nº 13.709/2018 — LGPD).

2. Quais dados este site coleta

Hoje, este site não possui formulários de cadastro nem ferramentas de rastreamento ativas (sem cookies de analytics, sem pixels de anúncio). O único ponto de contato é o botão de WhatsApp: ao clicar, você é levado para uma conversa no aplicativo WhatsApp, fora deste site — os dados trocados ali (seu número, nome, mensagens) ficam sujeitos à política de privacidade do próprio WhatsApp, não deste site.

Se, no futuro, este site passar a ter formulário próprio, cadastro ou chat integrado, esta política será atualizada para refletir exatamente quais dados passam a ser coletados e por quê.

3. Para que usamos os dados de contato

Quando você entra em contato pelo WhatsApp, os dados da conversa (nome, telefone, pedido) são usados exclusivamente para responder sua mensagem, elaborar orçamento e acompanhar a produção e entrega da sua encomenda.

4. Compartilhamento com terceiros

Não vendemos nem compartilhamos seus dados com terceiros para fins de marketing. A única "ponte" envolvida no contato é o próprio WhatsApp (Meta), necessária para a conversa acontecer.

5. Seus direitos (LGPD)

Você pode, a qualquer momento, solicitar:

  • Confirmação de que seus dados foram tratados
  • Acesso aos dados que temos sobre você
  • Correção de dados incompletos ou desatualizados
  • Exclusão dos seus dados de conversas anteriores

Basta enviar a solicitação para o e-mail abaixo.

6. Retenção

Conversas e dados de contato são mantidos apenas pelo tempo necessário para atender seu pedido e eventual pós-venda, podendo ser apagados a pedido do titular.

7. Contato do responsável

Dúvidas sobre esta política ou solicitações relacionadas aos seus dados: mikaele105@icloud.com
